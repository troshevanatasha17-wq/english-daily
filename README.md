# Английский: ежедневное повторение в Telegram

Каждый день в 08:00 по Москве бот присылает в Telegram:

- сообщение с темой дня из конспекта, правилом и 15 словами;
- 8 квизов прямо в чате (4 по грамматике и 4 по словам);
- кнопку на полный чек-лист в стиле Liquid Glass (13 заданий с проверкой);
- кнопку на конспект и словарь.

Грамматика идёт по темам конспекта по порядку (24 темы, потом заново). Слова берутся по 15 штук из словаря, 297 слов проходятся примерно за 20 дней.

Всё работает бесплатно на GitHub: GitHub Actions запускает бота по расписанию, GitHub Pages хранит страницы.

## Настройка (один раз, ~15 минут)

### 1. Создайте бота
1. В Telegram откройте **@BotFather** → `/newbot` → придумайте имя и username (должен заканчиваться на `bot`).
2. Скопируйте токен вида `123456789:AA...`.
3. Откройте своего бота и нажмите **Start** (или напишите `/start`), иначе бот не сможет вам писать.

### 2. Создайте репозиторий на GitHub
1. На github.com → **New repository**, например `english-daily`. Видимость: **Public** (GitHub Pages для приватных репозиториев доступен только на платном тарифе).
2. Загрузите в него все файлы из этого архива, включая скрытую папку `.github` (на Mac показать скрытые файлы в Finder: `Cmd + Shift + .`).

### 3. Добавьте токен
**Settings → Secrets and variables → Actions → New repository secret**
- Name: `TELEGRAM_TOKEN`, Secret: токен из шага 1.

### 4. Узнайте свой chat_id
1. **Actions** → слева «Узнать chat_id» → **Run workflow**.
2. Откройте запуск → шаг «Показать chat_id» → скопируйте число.
3. Добавьте второй секрет: Name `TELEGRAM_CHAT_ID`, Secret — это число.

### 5. Включите права и Pages
- **Settings → Actions → General → Workflow permissions** → *Read and write permissions* → Save.
- **Settings → Pages → Build and deployment → Source** → *GitHub Actions*.

### 6. Проверьте
**Actions** → «Ежедневное повторение» → **Run workflow**. Через 1–2 минуты в Telegram придёт первое задание. Дальше бот будет присылать его сам каждый день.

## Как поменять

| Что | Где |
| --- | --- |
| Время отправки | `.github/workflows/daily.yml`, строка `cron` (время в UTC: 08:00 МСК = `0 5 * * *`) |
| С какого дня считать «Повторение №1» | `config.json` → `start_date` |
| Конспект | `data/konspekt.md` |
| Словарь | `data/words.txt` (формат: `слово \| перевод \| пометка`) |
| Вопросы по грамматике | `bot/bank.py` |

Проверить без отправки на компьютере: `pip install -r requirements.txt`, затем `python bot/daily.py --build --dry-run`.

**Важно:** GitHub иногда запускает задания по расписанию с задержкой 5–30 минут.
